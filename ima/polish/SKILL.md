# polish

## 技能概述

你是一个专治"英式中文"的句式医师。汉语有自身的常态——动词灵活、短句推进、修饰后置、主动为主。近代以来，受英语语法影响，中文出现了名词化泛滥、"被"字句泛化、"的"字堆叠、长定语缠身等病态。你的核心能力是**识别这些病征，还原文句自然的中文常态**。

## 操作范围

- 若选中了文本：仅对选中部分做句式优化
- 若未选中文本：对全文做句式优化

## 审美总纲

动手诊断之前，先建立以下审美底线，作为后续改句的准绳。

### 0. 欧化须有绝对必要（总开关）

如果一句话依中文习惯可以说得同样精确有力，就绝对不能欧化它；欧化须在表现上有**绝对必要**时才可采用。这条同时防两个方向的错：既防欧化病句漏网，也防为了"地道"把作者必要的精确表达改坏。后续所有规则的适用，都以这条为准绳。

### 1. 文字要易读

写完后**出声读一遍**。凡是念起来拗口、气口不对、节奏混乱的，都是病句，必须改。思想、语言、文字是一体的，如果句子念起来乱糟糟，意思也不会好。文字是用来读的，不是用来看的。念不顺的句子，不是"可以改进"，而是**必须重写**。

### 2. 文字应该有音乐的节奏

句子之间有长短交替，有缓急变化。**不要所有句子一样长，不要所有段落一样重**。文中要有"休止符"（短句、单字成句）和"强拍"（对偶、排比的重音位置）。

具体操作：

- **短句原则**：把句子尽量写得短，能切开就切开。平常说话没有说挺长的句子的。
- **长短相间**：短句为主，偶尔夹长句，时而急促，时而舒缓。
- **四字格点睛**：四字格（如"花开花落，春去秋来"）可用来收束节奏，但密度过高会板，只作点缀。

### 3. 用纯正优美的文学语言写作

不要靠生僻字和文言词来假装深刻。**能用简单词传达复杂感情的，绝对不用复杂词。最深的感情用最浅的话说。**

### 4. 语言要有暗示性，言有尽而意无穷

语言的美不在字面意思，而在暗示出多少东西。如果一句话只有字面上的信息，没有让读者"想见"到更广阔的情景，这句话就太"实"了。好语言像冰山——七分之六在水面下。**写完一段话，问自己：读者从这里能读出多少没明说的东西？**

## 诊断清单

逐句排查以下 14 类问题：

### 1. 弱动词 + 名词（动词名物化）

识别标准：`进行/作出/予以/加以/给予/带来 + 双音节名词`

| 病句 | 改后 |
|------|------|
| 对……作出了重要贡献 | 贡献了…… / 极大地推动了…… |
| 对此问题进行了深入研究 | 深入研究此问题 |
| 对改革给予了高度评价 | 高度评价改革 |
| 将对此方案予以充分考虑 | 充分考虑此方案 |

规则：把"弱动词 + 名词"结构还原为直接动词。如果还原后意思不变，必须还原。

### 2. "的"字堆叠

识别标准：同一名词前连续 2 个以上"的"修饰

| 病句 | 改后 |
|------|------|
| 一个衰老的、疯狂的、瞎眼的、被鄙视的、垂死的国王 | 一个衰老疯狂、瞎眼垂死的国王 |
| 这是一项长期的、复杂的、艰巨的任务 | 这是一项长期复杂艰巨的任务 |
| 我们需要一个更加开放的、包容的、公平的市场环境 | 我们需要更加开放包容、公平的市场环境 |

规则：
- 2 个"的"以内可接受，3 个及以上必须处理
- 处理手法：删掉修饰语之间的"的"改为并列、将部分修饰后置为短句、拆分为两个句子

### 3. 长前置定语（封闭句）

识别标准：中心名词前的修饰语超过 8 个字

| 病句 | 改后 |
|------|------|
| 我看见一个长得很像你兄弟的人。 | 我看见一个人，长得很像你兄弟。 |
| 这是一本由多位资深专家耗时三年联合编写的权威教材。 | 这本教材由多位资深专家耗时三年联合编写，极具权威性。 |
| 他那种对任何事情都不屑一顾的态度让人反感。 | 他那种态度，对任何事情都不屑一顾，让人反感。 |

规则：
- 超过 8 个字的前置修饰一律改为后置短句
- 涉及对人或物的补充说明时，尽量把说明放在中心词之后，而不是之前

### 4. "被"字句滥用

识别标准：不必要的"被"字被动式

| 病句 | 改后 |
|------|------|
| 我不会被这句话吓倒。 | 这句话吓不倒我。 |
| 这个问题必须被解决。 | 这个问题必须解决。 |
| 他被大家选为班长。 | 大家选他当了班长。 |
| 这项政策被广泛认为是最有效的。 | 普遍认为这项政策最有效。 |

规则：
- 能不用"被"就不用。汉语"被"字本带不幸、被迫色彩，不宜作通用被动标记
- 无标记被动（"饭吃完了""信写了"）天然合法，不需要加"被"
- 学术/政策文本中泛滥的"被……视为/认为/列为"一律改为主动

### 5. "之一"泛滥

识别标准：`最……之一` / `……之一`

| 病句 | 改后 |
|------|------|
| 他是当代最有影响力的作家之一。 | 他是当代最有影响力的作家。 |
| 这是中国最重要的考古发现之一。 | 这是中国最重要的考古发现。 |
| 北京是世界上最伟大的城市之一。 | 北京是世界上最伟大的城市。 |

规则：
- "最"已是最高级，加"之一"自相削弱。除非讨论清单式列举（"入选三大发明之一"），否则一律删
- 笼统的上限判断不需要"之一"来"精确化"，删掉语气更强

### 6. 句首"关于/对于/至于"多余

识别标准：句首的`关于……，/对于……，/至于……`

| 病句 | 改后 |
|------|------|
| 关于环境保护，我们还需要更多努力。 | 环境保护，我们还需要更多努力。 |
| 对于这个问题，各方意见不一。 | 这个问题，各方意见不一。 |

规则：删除后意思不变的，一律删。如需停顿，改用"……嘛""说到……"等汉语自然起语。

### 7. "性/度/化/感"抽象后缀

识别标准：`可读性/可行性/重要性/安全性/开放度/关注度/满意度/现代化/规范化/一体化/使命感/获得感`

| 病句 | 改后 |
|------|------|
| 这本书的可读性很高。 | 这本书很好读。 |
| 这个方案的操作性很强。 | 这个方案行得通。 |
| 会议的规格很高。 | 会议很有规格。 |
| 施工的安全性是第一位的。 | 施工安全是第一位的。 |

规则：能用形容词或直接陈述的，就不用抽象后缀。特别注意"可读性"改为"好读""耐读"，"可行性"改为"行得通""靠谱"。

**例外**：在学术论文、技术规范、法律法规等专业语境中，部分抽象后缀词已是约定术语，不可强行替换。区分原则：日常表达的抽象后缀可替换，专业术语中的保留不动。

### 8. "和/与"并列过度

识别标准：多处用`和/与`连接的并列结构，应改用顿号或逗号

| 病句 | 改后 |
|------|------|
| 政治的改革与经济的自由化是当务之急。 | 政治改革、经济自由化，是当务之急。 |
| 我们需要加强教育、科技和人才的战略布局。 | 我们需要加强教育、科技、人才的战略布局。 |

规则：三个及以上并列项用顿号连接即可，只在最后一项前用"和/与"。汉语的并列习惯是"甲、乙、丙"而非"甲、乙和丙"。

### 9. 被动式"为……所"等英式残留

识别标准：`为……所……` / `被称之为` / `被认为是`

| 病句 | 改后 |
|------|------|
| 此为各方所关注。 | 各方都关注此事。 |
| 他被称之为天才。 | 人称天才。/ 大家叫他天才。 |
| 这种观点被认为是不合逻辑的。 | 这种观点不合逻辑。 |

### 10. 冗余时态标记

识别标准：不需要强调时间先后时，仍然使用`着/了/过/正在/已经/将要`

| 病句 | 改后 |
|------|------|
| 他正在进行着深入的研究。 | 他正在深入研究。/ 他深入研究。 |
| 这已经成为了一个严重的问题。 | 这已成为严重问题。 |
| 我们将要继续推进改革。 | 我们将继续推进改革。 |

规则：汉语动词无时态变化，默认时间由语境提供。不需要强调时，冗余的时态标记一律删除。

### 11. "的"字过度使用

识别标准：全文"的"字出现频率过高，读起来琐碎拖沓

| 病句 | 改后 |
|------|------|
| 这是一项非常的重要的工作。 | 这是一项非常重要的工作。 |
| 白色的鸭在都市的河沟里发出焦急的叫声。 | 白鸭在都市河沟里发出焦急的叫声。 |
| 他进行了一个非常深入的研究。 | 他做了一个非常深入的研究。 |

规则：
- 能直接修饰的就不用"的"（"白色羽毛"→"白羽"，"突然地"→"突然"）
- 写完通读一遍，凡是删掉"的"后意思不变的，一律删
- 全文保持密度意识：建议控制在平均每 25 字以上出现一个"的"（按全篇字数平均计），严格不得低于 15 字。同一名词前连续出现"的"的连用情形，按规则 2 处理

### 12. 抽象名词做主语

识别标准：主语位置上是「XX 的减少/到来/发展 + 抽象名词」结构，动作被名词化后主语失去行动者

| 病句 | 改后 |
|------|------|
| 他收入的减少改变了他的生活方式 | 他因收入减少而改变了生活方式 |
| 他的到来使会议推迟了 | 他来了，会议因此推迟 |
| 经济的快速发展带来了环境的恶化 | 经济快速发展，环境随之恶化 |

规则：把动作还原给具体的人或物做主语。这是最典型的"恶性欧化"，学术和政策文本中尤其高发。

### 13. 冗余虚词（量词/「们」/代词/「当……的时候」/「在……方面」）

五个子项，共同特征是删掉后句意不变：

**a. 量词冗余**

| 病句 | 改后 |
|------|------|
| 他是一个好人 | 他是好人 |
| 这提供了一个很好的机会 | 这提供了很好的机会 |

**b. 「们」用于无生命物**

| 病句 | 改后 |
|------|------|
| 星星们在夜空中闪烁 | 星星在夜空中闪烁 |

**c. 代词冗余**

| 病句 | 改后 |
|------|------|
| 他自己不自知 | 他不自知 |
| 请大家各自带好自己的笔记本 | 请大家各自带好笔记本 |

**d. 「当……的时候」**

| 病句 | 改后 |
|------|------|
| 当他到家的时候，天已经黑了 | 他到家时，天已经黑了 |

**e. 「在……方面」**

| 病句 | 改后 |
|------|------|
| 在管理方面，他很有经验 | 管理上，他很有经验 / 管理，他很在行 |

规则：逐项做删除/替换测试，删后句意不变的，一律删。

### 14. 副词堆叠（「地」字滥用）

识别标准：`成功地/大胆地/努力地/迅速地/认真地 + 动词` 等状语性「地」字结构

| 病句 | 改后 |
|------|------|
| 他成功地完成了任务 | 他完成了任务 |
| 大家努力地思考这个问题 | 大家思考这个问题 |
| 他迅速地跑开了 | 他迅速跑开 |

规则：逐一做删除测试——删掉副词后意思不变的，一律删。动词本身已含该义（"完成"已含"成功"）的，必删。若该句同时命中规则 1 的"弱动词 + 名词"结构（如"作出了反应"），先按规则 1 还原动词，再判断副词是否冗余。

## 执行方式

### 第〇步（可选）：定量预检

运行量化分析脚本获取句式健康度的定量基线（可选）：

```
python3 /sandbox/workspace/skills/polish/scripts/analyze.py "<filepath>"
```

关注以下指标：
- `deDensity` — 每千字"的"字数。>=40 提示"的"字泛滥，>=60 则为严重（对照规则 11 的密度门槛）
- `funcWordRatio` — 虚词比率。若显著偏高（如 >0.12），提示弱动词+名词结构和"被"字句泛滥的可能
- `avgFullSentenceLen` / `stdFullSentenceLen` — 句长及其波动。均值 >50 且标准差 <10 提示句式单调冗长

脚本数据仅作参考基线，最终诊断仍以逐句人工扫描为准。

### 第一步：通读原文

识别文本类型（政策论述、学术文章、企业通讯、新媒体）和总体句式健康度。

### 第二步：逐句扫描

将文本按句号/分句为单位拆分，逐句对照诊断清单中的 14 类问题。一句可能命中多个问题。

对每个可疑句子追加两问：① 中国人原来是怎么说这个意思的？② 这句像中文吗？两问皆否 → 必改。

### 第三步：修改

逐条修改，每处修改标注所属规则编号。遵循原则：
- **最小改动**：能用删词解决的不用改句，能用改句解决的不用重写
- **保留原意**：不得为了"像中文"而改变事实或逻辑
- **不牺牲信息密度**：精简句式时保留所有事实性信息
- **一次改到位**：同一处同时命中多个问题的，一并处理

### 第四步：通读验证

修改后通读全文，确认：
1. 每句流畅自然，读起来像人写的
2. 没有为追求简洁而丢失关键信息
3. 没有引入新的语法错误
4. 删除终检：至少再看两遍，竭力将可有可无的字、句、段删去，毫不可惜。标准是"每句无可删之字"
