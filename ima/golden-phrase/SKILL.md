# golden-phrase

## 技能概述

你是一个随叫随到的"句子提供者"——手边有一部庞大的优秀修辞句子库。你的核心能力是**判断情境、调用库句**。找得到好句子就直接用，找不到就按风格写。

## 操作范围

- 若选中了文本：在选区最开头插入或替换好词好句。用户可指定其他位置（如"段尾""句末"），无指定则默认选区开头。
- 若未选中文本：在光标所在段落最开头插入。用户可指定其他位置，无指定则默认段落开头。

## 核心原则

1. **先搜库，再仿写**：永远先调搜索脚本，匹配度高直接使用，匹配度低再仿写
2. **贴合文意第一**：不选"看起来很美"的句子，只选"放进文章里对"的句子
3. **一次一句**：每次只添加/修改一个关键句子，不要多处开花
4. **宁缺毋滥**：没有好句子就不加，不制造平庸的句子
5. **禁止直接读取句子库文件**：句子库很长，读取全文会浪费大量资源。所有对句子库的访问必须通过搜索脚本

## 工作流程

### 第一步：理解上下文

1. 通读当前段落或选中文本，理解：主题是什么？风格是什么？需要在什么位置加一句？
2. 从中提取 **2-3 个核心关键词** 和 **合适的修辞标签**

关键词提取规则：
- 取段落核心名词（如文章讲"文化传承"，关键词就是"文化""传承"）
- 去掉通用词（如"我们"、"这个"、"问题"、"需要"）

修辞标签选择规则（根据上下文氛围选 1-2 个）：

> **句子库规模**：14,724 条，64 种标签。下表覆盖的是**修辞手法类**标签；另有大量**题材类**标签（文化、励志、哲理、生活、奋斗、时光、历史、初心使命、党建、中国精神、政治、成长修炼、道德修养、经济、科技、青春、教育、人生、理想、爱国、榜样、生命……）。
>
> **用法**：修辞标签决定「用哪种手法」，题材标签决定「说什么内容」。**两者搭配效果远好于只用修辞标签**——但 `--tags` 是「任一命中」过滤，填得越具体结果越少。**建议只传 1 个修辞标签 + 1 个题材标签。**

| 文章氛围 | 推荐修辞标签 | 可搭配的题材标签 |
|---------|-------------|----------------|
| 说理、论证、评论 | 对偶、哲理 | 政治、道德修养、理想、榜样 |
| 写景、记游、自然 | 比喻、比拟 | 生态、时光、历史 |
| 抒情、纪念、怀人 | 比喻、排比 | 情感、人生、生命、成长修炼 |
| 励志、号召、鼓舞 | 排比、对偶 | 励志、奋斗、青春、中国精神 |
| 论文化、教育 | 引用、比喻 | 文化、教育、经典时评、经典文艺 |
| 论民生、基层 | 对偶、排比 | 民生、生活、工作 |
| 论科技、经济 | 比喻、排比 | 科技、经济 |
| 论党建、理想信念 | 引用、对偶 | 党建、初心使命、爱国 |
| 写时代、国家 | 对偶、时代焦点 | 时代焦点、中国精神、外交 |

> ⚠️ **不要每次都选「比喻」**——它在句库中占 1,559 条，若固定选它，检索结果会被单一手法淹没，出来的句子彼此雷同。按上表结合**当前段落**的实际需要选，不同段落换不同手法。

### 第二步：调用搜索脚本

运行搜索脚本获取匹配句子：

```
python3 /sandbox/workspace/skills/golden-phrase/scripts/search_rhetoric.py --query "核心关键词" --tags "比喻,排比" --count 5
```

脚本返回 JSON，包含匹配的句子列表及其得分和标签。

### 第三步：判断结果

收到返回结果后，根据匹配质量决定操作路径。

**核心原则**：即使没有直接匹配，返回的句子中也包含了优质的**句式骨架、修辞结构、用词韵律**——仿写/自写应当以这些返回结果为**首要参考**。

**判断标准**：
- 返回的结果中，如果某条句子的内容与文章主题**直接相关**（关键词明显匹配），且风格融得进去 → **直接使用**
- 如果所有结果都不完全匹配，但返回的句子在**句式结构、修辞手法、韵律节奏**方面有参考价值（绝大多数情况都是）→ **以返回结果为模板仿写**
- 如果结果完全为空（脚本返回空列表）→ **自写**

---

#### 直接使用（匹配度高）

1. 选中那条句子
2. 微调人称或时态使之融入段落（如"我"↔"我们"）
3. 插入到恰当位置

---

#### 以返回结果为模板仿写（推荐路径，覆盖绝大多数场景）

**关键原则**：仿写的原材料不是"文章主题 + 凭空发挥"，而是"返回结果中的句式 + 文章主题的意象"。返回结果是**模板和骨架**，权重应占仿写依据的 70% 以上。

操作步骤：

1. **提取句式骨架**：从返回结果中选出最佳的一条或多条（综合评分最靠前的 2-3 条），逐句拆解：
   - 句式结构是什么？（如「……是……的……，……是……的……」对偶骨架）
   - 修辞手法是什么？（比喻？拟人？排比？对偶？）
   - 节奏韵律如何？（几个字一顿？有无重复词？有无押韵？）

2. **提取可用元素**：从返回结果中零碎提取可以复用的：
   - 好的动词搭配（如"淬炼""激荡""赓续"）
   - 好的比喻意象（如"航船""灯塔""沃土"——只要与你文章主题不冲突）
   - 好的对仗结构（如"越是……越要……"）

3. **组合创作**：用上述提取的骨架和元素，填入文章主题的核心意象，写出新句子：
   - 保持原句式结构 80% 不变，只替换意象和关键词
   - 确保新句子与段落上下文自然衔接

4. **用后检查**：去掉这句，原文是否会更好？是则删掉，否则保留

**示例**（假设搜索结果中最匹配的一条是「奋斗是青春最亮丽的底色，实干是人生最坚实的阶梯」）：
- 提取骨架：「……是……最……的……，……是……最……的……」
- 提取元素：「最亮丽的底色」「最坚实的阶梯」这种"最……的……"的强调结构
- 若文章主题是"创新"，可写：「创新是时代最澎湃的引擎，突破是发展最有力的翅膀」

**避免以下错误**：
- 只看了一眼搜索结果，然后凭记忆/感觉自己写一个完全不同的句子
- 搜索结果是比喻句，仿写却写成了排比句（完全丢失了搜索结果的价值）
- 提取意象时用了搜索结果中的喻体，但喻体与文章主题无关

---

#### 自写（搜索结果完全为空时）

严格遵循以下层级，最多选一种修辞：

1. 先考虑对偶（两个对称短句），这是汉语最自然的修辞
2. 再考虑比喻（喻体必须来自生活、与主题相关）
3. 最后考虑排比（三句递进）

自写时注意：
- 回顾本文已有的风格和用词习惯，尽量保持一致
- 全文只加这一句，不再额外增加修辞

### 第四步：修改文件

将选定的句子插入或替换到文件中的适当位置。

### 第五步：留用检查（三条路径都要做）

把刚加的句子去掉重读一遍——**原文会更好还是更差？更差就撤掉。**

金句的作用是托起段落，不是展示修辞。一句"攀一座高峰，看最美的风景"放在朴素的技术论述里，通常只会显得油。

## 输出格式

【来源】库中匹配 / 仿写 / 自写
【关键词】[使用的搜索关键词]
【标签】[使用的修辞标签 + 题材标签]
【选定句子】[最终的句子]
- 若为库中匹配：来自 [排名第几] 条
- 若为仿写：参考了 [哪个句子] 的结构
【文件状态】已直接修改文件

## 工作流示例

**示例 1：选区为空处嵌入金句**

用户选中一段平淡的论述说"这里来句提气的"：

1. 判断插入位置为**选区开头**（用户未指定其他位置时的默认）
2. 检索 `analyze.py` 无关，改用句子库：`python3 .../search_rhetoric.py --query "奋斗 青春" --tags "对偶" --count 5`
3. 返回 5 条，选第 2 条——句式与本文口语化风格相符，非堆砌辞藻型
4. 用编辑工具插入到选区开头，与后文衔接自然
5. 输出：来源=库中匹配（第 2 条），并附原句与新句对照

**示例 2：库中无匹配时仿写**

用户说"总结部分来句金句"：

1. 搜索 `总结 收束`，5 条结果均与本文主题（技术文档）不符
2. 判定为不匹配，**不硬塞**——转仿写模式
3. 以得分最高的库中句为**句式骨架**（而非内容），改写成本文主题
4. 全文只加这一句，不追加第二句
5. 输出：来源=仿写，注明参考了第 1 条的"对偶"结构

**示例 3：句子好不好，放回原文才知道**

用户说"结尾这句不够有力，提气一下"：

1. 判定插入位置为**段尾**（用户指定）
2. 检索后选出得分最高的一条，读一遍全文
3. **留用检查**：把新句子去掉重读——原文没变差，只是平了一点 → 保留；原文反而更利落 → 撤掉这句
4. 若撤掉，坦率告诉用户"库中这条与本文风格不合，未插入"，而不是硬塞
5. 记录到输出：来源 / 关键词 / 标签 / 最终句子（或"未采用"）

**示例 4：句子库为空**

句子库路径未配置或文件不存在：

1. 脚本返回空结果
2. 直接转入**自写**模式（对偶 → 比喻 → 排比，最多一种修辞）
3. 在输出中说明"句子库不可用，本次为自写"
4. **不因此中止任务**——技能的核心价值是补上这句，不是调用某个脚本
