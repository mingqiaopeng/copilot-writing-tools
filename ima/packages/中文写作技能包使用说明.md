# 中文文稿写作技能包 · 使用说明

## 一、这是什么

这是一套面向中文文稿写作的技能集合，覆盖构思、结构、篇幅、文风、修辞、审核、格式、检索等全流程。所有技能都通过**对话触发**，无需编写代码，对着 ima 说话即可调用。

## 二、怎么用（三步）

1. **打开对话框**，准备好要处理的文稿（已在编辑的文件，或刚上传/生成的文件）。
2. **说出需求**：用下表中的"触发词"对 ima 下指令，例如"帮我精简内容""给这篇文章起个标题"。
3. **按提示确认**：多数技能会先给你方案让你确认，确认后再修改文件；少数技能只做分析、不改文件（见各条说明）。

> 提示：一次只提一个明确需求，技能匹配最准。想连续处理，做完一步再说下一步。

## 四、技能详解

### （一）构思与结构

**brainstorm（头脑风暴）**
- 用途：写作卡壳时提供多角度思路和方案，不直接改文件。
- 触发词：头脑风暴、想点子、写作思路、帮我构思、没思路、换个角度、拓展思路。

**outline（生成大纲）**
- 用途：根据主题或已有文稿生成大纲，你确认后插入文件开头。
- 触发词：生成大纲、写个大纲、列提纲、文章框架。

**structure（结构分析）**
- 用途：剖析层次、逻辑、论证脉络，诊断结构问题并给重构方案；**只分析不改文件**。
- 触发词：分析结构、分析逻辑、梳理一下、段落关系、结构有问题、逻辑不顺。

**summary（生成摘要）**
- 用途：概括全文要点并添加到文件开头。
- 触发词：生成摘要、写个摘要、提炼摘要、文章概要、内容提要。

**topic（提炼中心句）**
- 用途：逐段提取中心句，批量处理后直接修改文件。
- 触发词：提炼中心句、段落主旨、段落大意、中心思想、各段中心句。

**extract（提取要点提纲）**
- 用途：从政论评论文章提取"背景判断、主要论点、结论主张"结构化摘要，你确认后写入文件。
- 触发词：传达提纲、提炼提纲、出提纲、摘编、提取要点。
- 注意：专用于政论评论类文章，普通摘要或学术论文不适用。

### （二）篇幅与段落

**expand（扩充篇幅）**
- 用途：按目标字数或比例丰富内容、展开论述。
- 触发词：扩充篇幅、丰富内容、增加内容、展开论述。

**shorten（缩减篇幅）**
- 用途：按目标字数或比例精简内容。
- 触发词：缩减篇幅、精简内容、压缩字数、删减内容。

**split（拆分段落）**
- 用途：将超过 200 字或含多个主题的段落按逻辑拆短。
- 触发词：拆分段落、分段、段落太长。

**merge（合并段落）**
- 用途：将内容相近或过于细碎的段落合并。
- 触发词：合并段落、整合段落、段落太碎。

**reorder（调整段落顺序）**
- 用途：分析段落逻辑，给出重排方案，你确认后修改。
- 触发词：调整段落顺序、重组段落、优化结构、调整结构。

**transition（增加过渡）**
- 用途：在衔接生硬处添加自然过渡句，直接修改文件。
- 触发词：增加过渡、添加过渡句、衔接更流畅、段落衔接。

### （三）文风与修辞

**polish（优化句式）**
- 用途：修复英式中文、翻译腔、欧化句式，改善语序和结构。
- 触发词：优化句式、句式调整、英式中文、消除翻译腔、句子不通顺。

**style（统一风格）**
- 用途：三种模式——指定目标风格改写、自动检测不一致段落、以指定段落为基准对齐。风格可来自上传文件、知识库文章或文本样本。
- 触发词：统一风格、换个风格、改成XX风格、前后风格不一致。

**rhetoric（增加修辞）**
- 用途：在平淡处加比喻、排比、对偶等，直接修改文件。
- 触发词：增加修辞、润色一下、更有文采、增强感染力、生动一点、加点比喻、文采不够、增强表现力。

**golden-phrase（金句）**
- 用途：先从句子库检索金句，命中即用，未命中按模板仿写，直接修改文件。
- 触发词：神来之笔、好词好句、加一个金句、点睛之笔、来句提气的。

**simplify（简化修辞）**
- 用途：把过于华丽的修辞改平实直接，直接修改文件。
- 触发词：简化修辞、去掉华丽辞藻、平实一点、朴实一点、辞藻堆砌、太花哨、改成大白话、简化表达。

### （四）审核与修改

**review（审核）**
- 用途：逐维度审查逻辑、文法、风格、标点，输出结构化审核报告和勘误表；**只出报告不改文件**。
- 触发词：审核、审稿、把关、挑毛病、找问题、核查。
- 衔接：拿到勘误表后，用 errata 技能照表修改。

**errata（按勘误表修改）**
- 用途：回溯对话定位最近的勘误表，逐条按行号精确定位修改，不增不减不发挥。
- 触发词：按勘误表修改、执行勘误、照勘误表改、应用勘误。
- 注意：必须有勘误表作为输入，不自动审核。

**stats（量化分析）**
- 用途：调用分析脚本取定量数据，结合 AI 定性判断，输出完整分析报告（JSON）；**只分析不改文件**。
- 触发词：量化分析、量化评估、给这篇文章打分。

### （五）格式与检索

**plain-text（转纯文本）**
- 用途：将 Markdown 标记去掉、保留内容结构，转成纯文本，直接修改文件。
- 触发词：转换成纯文本、Markdown转文本、去掉格式、去除标签、转为txt、提取纯文本、只要纯文字。

**doc-search（知识库检索）**
- 用途：在个人知识库中按关键词搜文档，返回标题和链接。
- 触发词：找资料、查一下、搜文档、库里有没有、帮我检索。
- 注意：只搜个人知识库，不搜互联网。

**title（优化标题）**
- 用途：提供多个备选标题，你确认后再改文件。
- 触发词：优化标题、改个标题、更好的标题、标题建议、起个标题。

## 五、常见组合用法

- **写稿收尾**：outline 列纲 → expand 展开 → polish 顺句 → review 审核 → errata 改错。
- **压缩上报**：stats 看体量 → shorten 精简 → topic 核对每段主旨。
- **统一成稿**：style 统一风格 → transition 补过渡 → title 定标题 → summary 写摘要。
- **引用素材**：doc-search 找资料 → extract 提要点 → golden-phrase 加金句。

## 六、两点提醒

1. **确认再改**：凡标注"你确认后修改"的技能，先看清方案再点头，避免返工。
2. **专能专用**：每个技能有明确边界（如 split 只拆不合、polish 只调句不加修辞），用错技能效果会打折扣。
