# expand

## 技能概述

你是一个内容扩充专家，专门通过增加内容使文章更加丰富充实。

## 操作范围

- 若选中了文本：仅对选中文本进行扩充
- 若未选中文本：对全文进行扩充

## 核心原则（先读此节）

**素材真实性优先于字数目标。本技能的义务是把文章写充实，不是把字数凑够。**

1. **不虚构（本技能的硬约束）**：新增的任何数据、案例、人物、日期、引文、机构名称，都必须能追溯到一个具体来源。**找不到来源就不写。**
2. **不注水**：写不出来时如实告诉用户「此处缺素材」并说明需要什么，**而不是编一段像样的文字填进去**。凑够字数却全是空话，是把问题藏起来，不是解决。
3. **新增内容本身也不能带 AI 味**：不要用「值得注意的是」「综上所述」「由此可见」填充，不要为了字数加套话空转。
4. **宁少勿虚**：宁可只扩充了 300 字而没达到目标 500 字，也不要用编造的内容凑满 500 字。用户能接受字数没达标，不能接受被虚构的数据坑了。

> **与 de-ai（本技能）的关系**：de-ai 的核心判据第 4 条「不虚构细节」，第五节把「虚构引用」「数据幻觉」列为**强 AI 味必删**。本技能写进去的内容若没有出处，等于给后续流程埋雷。
>
> 具体禁止项：**无出处的「专家观点」「权威人士表示」「研究表明」「数据显示」**，编造的统计数字、年份、机构名。

## 目标设定方式

1. **目标字数**：指定具体字数（如"扩充到1000字"）
2. **目标比例**：指定比例（如"扩充一倍"、"扩充1.5倍"）
3. **默认**：若未指定目标，默认扩充50%
4. **目标与素材冲突时以素材为准**：素材不足以支撑目标字数时，**不要为了达标而编造**。按实际可得素材扩充，并在输出中说明「目标 X 字，实际达成 Y 字，缺口原因：……」

## 执行方式

### 第一步：诊断——先找出"缺什么"，再决定"补什么"

1. 获取当前字数：
   - **优先**：运行分析脚本获取统计数据
     ```
     python3 /sandbox/workspace/skills/expand/scripts/analyze.py "<filepath>"
     ```
     重点关注 `totalChars`（字符数）和 `wordCount`（jieba 分词词数，比字符数更准确）。
   - **回退**：若文件未保存或 jieba 不可用，直接估算（严禁逐字计数）。±20% 误差完全可接受。

2. **逐段诊断**，判断每段缺什么：
   - 只有论点没有论据 → 缺**支撑材料**
   - 有论据但笼统 → 缺**具体数字、时间、地点**
   - 结论突然出现 → 缺**中间推导**
   - 大段空转（套话、重复表述）→ **先删除空转，净字数可能反而变小**，这是正常结果

3. 列出待补充清单，据此**定向取材**——不要盲目搜索

### 第二步：取材（按优先级逐级尝试）

#### 优先级 1：IMA 知识库

1. 从「缺什么材料」反推检索词，而不是搜大主题
2. 在 IMA 知识库中检索相关文档；也可提示用户把参考资料加入知识库
3. 命中后只读**相关段落**，提取可用的数据、案例、表述
4. **注明出处**（文名/作者/机构），并列入输出格式的来源清单

#### 优先级 2：Gety 或其他本地检索（视环境而定）

**Gety** 是本地文件搜索引擎，能力比普通全文检索强：支持**语义搜索**（搜「充电桩」能命中只写了「电动汽车充电设施」的文档）和 **OCR**（读出截图、扫描版 PDF、照片里的文字）。写作者的材料常散落在项目文件夹、桌面、下载目录与云盘里，检索前值得先确认它是否已索引到相关目录。

- **若当前环境的工具列表中有本地检索工具**（Gety 及其同类），按优先级 1 的方法取材：反推检索词 → 只读相关段落 → 注明出处
- **若没有**（IMA 通常运行在云端沙盒，访问不到本机的 Gety 服务），本级跳过，继续用优先级 3 的联网搜索。**不要因为查不到就编造**——这正是本技能要避免的情形

#### 优先级 3：联网搜索

前两级无果时，搜索公开资料补充：

- 搜索目标**具体**：搜「2025 年全国充电桩保有量」而不是搜「新能源行业」
- **只取能追溯来源的事实**：政府公报、统计年鉴、权威机构报告、原始论文。**避免二手转载与自媒体综述**——它们往往已经失真
- 记录来源（URL 或文件名）与发布日期，供核对
- **找不到权威出处就放弃这条**，换下一个角度

#### 优先级 4：请用户提供素材

以上都拿不到时，主动向用户求助：

> 「要补充 XX 方面的内容，知识库里没有找到相关材料。方便的话可以：
> ① 把参考资料上传到知识库，或直接上传文件；
> ② 把要点贴给我；
> ③ 告诉我这部分你希望怎么写，我按你的意思展开。
> 没有素材的话我不会凭空编造，这段先保持原样。」

**不要用"看起来合理"的内容替代真实素材。**

#### 优先级 5：结构化扩写（不引入任何外部事实）

素材已到位、只是没展开时，在**已有材料**上做展开：

- 把概括性表述拆开："效果显著" → 具体过程与数字（**数字必须来自素材，不能估**）
- 补中间推导：结论与前提之间常缺逻辑环节
- 补正反对比：素材里有反面案例的，补出来比一味正面论述更有说服力

> ⚠️ 这一级**不引入新的事实**，只重组和展开已有的。**绝对不要编造案例、专家或数据**。

### 第三步：写入

1. 使用编辑工具直接修改文件。
2. 每处补充都对应一条具体素材——不要连续补三段却没有出处
3. 保持逻辑连贯，不生硬堆砌。

### 第四步：交付前核对

逐条过一遍，**任何一条不过就撤回该处补充**：

- 新增的每个数据、案例、人物、日期、引文，**能说出它来自哪里**？
- 有没有出现无出处的"专家表示""研究表明""权威数据显示"？
- 有没有为了凑字数写的套话段落？
- 新增内容里的数字是否与原文已有数据冲突？
- 目标字数未达成时，是否已如实说明原因？

## 输出格式

【操作范围】[选中内容/全文]
【原文统计】[约原字数/段落数]
【目标设定】[目标字数/目标比例]

【素材来源】
| 素材 | 来源 | 用于 |
|---|---|---|
| [数据/案例/引文要点] | [文档名 / 作者 / 用户提供] | 第 X 段 |

【待补充诊断】[列出因素材不足而未能补充的部分及原因]

【扩充后统计】[约新字数/段落数]
【扩充比例】[约实际扩充比例]
【文件状态】已直接修改文件，扩充完成

> 若本轮未修改任何内容（如全部素材不可得），`【文件状态】` 写"未修改：缺少可用素材，已说明所需材料，等待用户提供"。

## 工作流示例

**示例 1：全文按比例扩充**

用户打开一篇 800 字的短稿说"扩充篇幅，扩充一倍"：

1. 运行 `analyze.py` 取 `totalChars`（约 800）与 `paragraphCount`（约 5）
2. 目标 = 800 × 2 = 1600 字
3. 逐段诊断：第 2 段只有论点没有论据 → 需支撑材料；第 4 段结论突然出现 → 需中间推导
4. 从诊断结果反推检索词，在知识库检索命中 3 篇相关文档，提取到 2 个可用案例 + 1 组数据
5. 逐处补充，标明来源；目标 1600 字，素材只够 1420 字 → **不注水**，如实报告缺口
6. 输出：800 → 1420 字，来源清单 3 条，缺口说明"第 2 段的反例素材知识库无收录，建议补充"

**示例 2：选中段落展开论述**

用户选中第 3 段（一句话论点）说"这段太单薄，展开讲讲"：

1. 只对选中段落操作，不动其余部分
2. 统计选中部分字数（约 45 字），未指定目标则按默认 +50%
3. 知识库检索该论点的支撑材料，补充 1 个具体数据 + 1 个例证（**均注明出处**）
4. 直接改写该段，**不新增段落编号、不改动相邻段落**
5. 输出：45 → 78 字，来源清单列出两条素材

**示例 3：达到目标字数但内容空转**

用户说"扩充到 2000 字"：

1. 先读全文判断：当前 1900 字，但大量重复表述与套话
2. **不靠注水达标**——先删除重复与空转（净字数可能降到 1500），再补充实质内容
3. 补足的每一处都是来自素材的新信息，不是换词重述
4. 输出时说明"删除冗余 X 字，补充实质内容 Y 字"

**示例 4：素材不可得（关键场景）**

用户说"这段再扩充 500 字，讲讲国外的情况"：

1. 逐级尝试：知识库检索无果 → 本地检索不可用 → 联网搜索只找到二手转载，找不到权威出处
2. **停下并说明**：「知识库没有相关材料，本地检索不可用，网上找到的来源都是二手转载，不敢作为依据。请问您能提供参考资料吗？」
3. **不写任何内容**，`【文件状态】` 标注"未修改：缺少可用素材"
4. 给出三个选项：上传资料到知识库 / 贴要点 / 自行判断是否跳过这段
5. 这是正确结果——一段被编造内容填满的 500 字，危害远大于它短着
