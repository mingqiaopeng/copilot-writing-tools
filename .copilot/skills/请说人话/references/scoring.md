# 请说人话 · AI 味评分体系

> 需要给「AI 味」一个量化总分时，从以下三套体系中任选其一。评分结果用于自测与复核，不替代逐项改写。

---

## 一、累加扣分制（the-antislop）

**中文 AI 味高频词表**（每处 +3）：

| 类别 | 词 |
|------|-----|
| 提示型元话语 | 值得注意的是、需要指出的是、值得一提的是、不可忽视的是、必须强调的是 |
| 总结型收束 | 总的来说、综上所述、总而言之、由此可见、不难看出、换句话说 |
| 模糊限定 | 某种意义上、某种程度上、在一定程度上、从某种意义上说 |
| 伪深刻 | 本质上、实质上、根本上、事实上、实际上、说到底 |
| 保险词 | 可以说、应该说、通常来说、在某种程度上 |
| 避讳「是」 | 标志着、发挥着、扮演着、诠释着、象征着、诠释着 |
| 空泛搭配 | 具有重要意义、产生深远影响、发挥积极作用、值得深思、引人深思 |
| 外交/公文套话 | 深入探讨、深入解析、深入拆解、赋能、助力、聚焦、抓手、闭环 |

**其他模式**：

| 模式 | 分值 |
|------|------|
| Tier 2 重复（同一句式在全文反复出现，如每段都用「不仅…而且…」） | 重复出现 +2 |
| Tier 3 聚簇（转折词开头成癖：每段以「然而」「此外」起句） | 成簇 +2 |
| 碎片 spam（短句连发制造假节奏：「快。狠。稳。」） | +4 |
| 伪造个性（假装毒舌、装出来的网感） | +4 |

**判读**：0-5 低风险 ｜ 6-12 中风险（需大幅编辑）｜ 13+ 高风险（大概率未修饰的 AI 文本）

## 二、五维评分制（stop-slop，各 1-10 分，满分 50）

| 维度 | 核心问题 | 低分（1-3）表现 | 高分（8-10）表现 |
|------|----------|------------------|------------------|
| Directness 直接性 | 在陈述，还是在宣布？ | 清嗓子、铺垫、预告 | 直接陈述 |
| Rhythm 节奏 | 句长自然变化，还是像节拍器？ | 等长句连续 | 长短交错、段尾各异 |
| Trust 信任 | 尊重读者智商吗？ | 手把手解释、过度辩护 | 相信读者 |
| Authenticity 真实 | 听起来像人写的吗？ | AI 模式可检出 | 有人味和立场 |
| Density 密度 | 有没有可删的？ | 填充与冗余 | 每个词都在挣钱 |

**判读**：<35/50 → 重写。

快速自检：
- 连续三句等长？打断一句。
- 段落以精练短句收尾？换个收法。
- 破折号出现在揭示句前？删掉。
- 在解释比喻？相信它能落地。

## 三、节奏基线（由 analyze.py 实测，不合成总分）

> **本节不给 0-100 的合成分数。** 三项指标的量纲、适用条件各不相同，强行加权得到的数字只是"看起来算过"，实际不可靠——这与本技能「不虚构、纪律优先于规则」的总则冲突。**报出三项实测值 + 各自的判断，读者自行综合。**

运行 `analyze.py` 后取以下字段：

| 指标 | 怎么算 | 怎么看 | 局限 |
|------|--------|--------|------|
| **句长变异系数 CV** | `stdFullSentenceLen ÷ avgFullSentenceLen` | 无量纲，**可跨篇幅、跨文体比较**。这是 burstiness 的标准定义 | 经验分档，非验证过的阈值 |
| **句长跨度** | 配合 `avgFullSentenceLen` 看 | 文中有无 4–8 字短句与 30+ 字长句交替；只有中长句而无短句 = 节奏单调 | — |
| **词汇多样性** | `lexicalDiversity` | 同一作者的相近篇幅文本之间可比 | ⚠️ **不可跨篇幅比较**：TTR 随文本变长而自然下降。5000 字与 500 字风格相同也会数值不同 |
| ~~FK 可读性~~ | — | **本工具未实现**，analyze.py 不输出该指标 | 英文式年级公式对中文适配性差，故不纳入 |

### CV 经验分档

| CV | 判断 | 建议 |
|-----|------|------|
| < 0.35 | 句长高度均匀，AI 特征明显 | 主动插入短句，制造长短落差 |
| 0.35 – 0.55 | 适中 | 无需处理 |
| > 0.55 | 波动充分，人工特征明显 | 保持 |

> 上述分档是**经验值**，来自对中文学术/评论类文本的粗略观察，未经语料库统计验证。当作参考基线，不当作判定结论——核心判据第 1 条仍然成立：**存在 ≠ 滥用，密度才是**。

## 附：实证背景（这些规则为什么可信）

> 以下研究的对象多为**英文**语料。它们的结论要迁移到中文，靠的不是词表本身，而是**规律**：「模型为了统计安全，会高频复用同一批低信息量词」——这一现象与语言无关。中文 AI 味的高频词表（本文件第一节）是按同一规律独立整理的，未经同等规模的语料统计。

| 研究 | 样本 | 发现 |
|------|------|------|
| 芬兰作文研究 | 56,878 篇作文 | 「delve」用量在 ChatGPT 之后增加 **10.45 倍** |
| Georgia Tech 论文分析 | 1.683 亿篇文章 | 「delve」从 0.31/千词 → **7.9/千词**（2024 Q1） |
| 生物医学文献研究 | 2023-2024 | delve / realm / underscore 共现增加最高 **85 倍** |
| Louis Abraham PR 分析 | 461,000+ GitHub PR | 2026 年 **45% 的人类署名 PR** 共享同一 LLM 词汇簇：load-bearing（+123x）、seam、quietly、latent、genuine |
| Copyleaks 文体指纹研究 | — | 统计特征（burstiness 等）可稳定区分人机文本 |
