# Continue .prompt 输出规范 v2.0

## Unified Diff 格式（Continue 原生支持，所有模型可用）

每个修改点输出一个 unified diff 块，Continue 自动识别为 Instant Apply：

```diff
@@ -起始行,行数 +起始行,行数 @@
 未修改的上下文行（行首空格）
-删除的原始文本（行首减号）
+新增的替换文本（行首加号）
 更多未修改的上下文行
```

**语法规则：**
- `@@ -a,b +c,d @@` 为 hunk 头，标记修改位置（行号大致准确即可）
- ` ` 前缀 = 未修改的上下文（保持在原文中定位修改位置）
- `-` 前缀 = 删除的行
- `+` 前缀 = 新增的行
- 多个独立修改 → 多个独立 hunk，放在同一个 diff 块中
- hunk 之间用空行分隔
- 代码块语言标记为 `diff`

## 最小修改原则（铁律）

- 改了一个段落 → 只输出一个 hunk，上下文只包含该段落
- 改了三个段落 → 输出三个 hunk
- 插入内容 → `+` 行放在插入位置
- 选中了文本 → 只输出选中范围内的 hunk
- 全文生效的修改 → 才输出完整文件的 hunk
- **绝对禁止**输出未被修改的全文或段落

## 示例

### 插入类（段首加中心句）

```diff
@@ -5,1 +5,2 @@
 段落原有第一句话开始……
+【中心句】段落原有第一句话开始……
```

### 替换类（修改某段落）

```diff
@@ -10,3 +10,3 @@
 上文保持不变
-原来的段落全文，一字不差
+修改后的段落全文
 下文保持不变
```

### 多条勘误

```diff
@@ -12,1 +12,1 @@
-己经
+已经
@@ -15,1 +15,1 @@
-致关重要
+至关重要
```
